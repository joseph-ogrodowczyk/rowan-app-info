Rowan Self-Scheduler

Rowan Self-Scheduler is a personal research and operational assistant maintained by Joseph Ogrodowczyk. It helps organise selected working records, maintain continuity and prepare research reports.

This is an information website for a privately operated application. It offers no public registration and does not request Google credentials.

How the application works

The application runs its research host in GitHub Actions. With the account holder’s authorisation, it retrieves configured Google Drive records, passes selected content to OpenAI Codex for analysis, and saves reports to a configured Google Drive folder.

Google Drive access

The application requests permission to read Drive files and permission to create or manage files created by, or explicitly opened with, the application. Its configured source selection is narrower than the account-level read permission. The combined permission is not read-only.

Google authorisation takes place through Google’s own consent screen. Read the privacy policy for details about processing, storage and revoking access, and the use information for the application’s intended use.
