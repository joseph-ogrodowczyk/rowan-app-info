Google data and privacy

Privacy policy

This policy describes the personal application Rowan Self-Scheduler, operated by Joseph Ogrodowczyk, and this public information website.

Data accessed and purpose

The application uses Google OAuth permissions https://www.googleapis.com/auth/drive.readonly and https://www.googleapis.com/auth/drive.file. These allow reading Drive content and creating or managing application-created or explicitly opened files. The runtime selects configured file identities and checks their identity, type and version.

Selected document content and file metadata are used to maintain working continuity, analyse project records and produce research and operational reports. Reports may include material derived from those records.

Processing and service providers

Google Drive supplies source records and stores output reports. GitHub Actions hosts execution; selected content is staged in its execution workspace. Selected content is then provided to OpenAI Codex for processing. GitHub also hosts private operational state. Google data therefore leaves Google Drive for this processing.

This public repository contains the informational website, not the private runtime or source records. The website has no sign-in form, application database, analytics script or credential collection. GitHub Pages hosts it and may record visitor information, including IP addresses, under the GitHub Privacy Statement.

Storage and security

Drive OAuth credentials are stored as GitHub-managed secrets. Operational state is maintained in an encrypted private ledger. The analysis container receives selected source content and separate Codex authentication, rather than the host’s Drive OAuth or GitHub credentials. These controls do not guarantee that a security incident cannot occur.

Retention and deletion

Drive source records and completed reports remain until the account holder removes them. Private operational records can persist in repository history or retained copies; removing a current file does not necessarily remove historical copies. The application has no single automatic deletion period covering all of these records.

GitHub execution records, logs and artifacts, and OpenAI processing records, follow the applicable account settings and provider retention policies. This application does not promise a specific deletion period for provider-held records or backups. See the OpenAI Privacy Policy and GitHub’s policy for provider information.

Your controls

You can revoke Google access through Google Account connections. Revocation stops future authorised access; it does not automatically delete existing reports, operational history or copies already processed by providers. Account holders can remove their Drive files and contact the operator for help identifying and removing application-controlled retained data. Provider-held records may require provider-specific controls or requests.

Contact and changes

For privacy questions or deletion requests, contact Joseph Ogrodowczyk at joseph.ogrodowczyk@gmail.com. Requests are handled by the operator; no automatic deletion service is offered. Material changes will be reflected on this page with an updated date.
